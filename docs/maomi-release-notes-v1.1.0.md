# 小猫咪 1.1.0 发布说明

- 发布日期：2026-09-16
- Git 标签：`maomi-v1.1.0`
- 上一版本：`maomi-v1.0.0`
- 板型：`zhengchen/1.54tft-wifi-maomi`
- 芯片：ESP32-S3，16 MB Flash，8 MB PSRAM
- ESP-IDF：6.0.2

## 新增功能

- 新增专注计时模式。倒计时启动后退出当前语音会话，保留本地唤醒，并在屏幕上持续显示剩余时间。
- 倒计时支持暂停、继续和停止；暂停时冻结剩余时间并显示暂停标记。
- 新增正计时，支持暂停、继续、归零和停止，显示上限为 `99:59:59`。
- 倒计时和正计时共用唯一前台计时位置，避免语音控制目标和屏幕归属不明确。
- 唤醒成功并播放本地猫叫后直接进入聆听，不再请求服务器欢迎语。
- 新增聆听动画；音量上键双击摸摸时增加离线语音“摸摸好舒服呀！”。

## 行为调整与修复

- 倒计时到点可以中断聆听或说话并立即显示提醒；声音忙时会在播放通道空闲后重试。
- 计时过程中进入聆听时暂时隐藏计时图层，返回待命后恢复显示。
- 闹钟、喝水提醒、久坐提醒和番茄钟仍可在专注计时期间按原优先级提醒。
- 普通“陪我玩”不再触发空玩耍动画或增加亲密度；玩耍反馈只在六种真实语音游戏开局时触发。
- `self.pet.interact` 只接受摸摸和喂食；新增统一计时控制工具及正计时启动工具。

## 兼容性

- 保持板型与 OTA 身份 `zhengchen-1.54tft-wifi-maomi` 不变，可从 1.0.0 升级。
- 不改变原版 `zhengchen/1.54tft-wifi` 的引脚、工厂函数或运行行为。
- 本版本未引入 NVS 键迁移；现有亲密度、陪伴天数、提醒和设置数据保持兼容。
- 英语学习功能仍处于需求澄清阶段，不属于本版本交付范围。
