# 猫咪生活扩展：使用和验证

本轮扩展单只橘猫的生活与成长，学习赚币仍只用已完成的单词小老师。
倒计时、正计时、暂停/继续/停止、提醒、专注、原有语音娱乐游戏和 AI 对话继续保留。
完整规则见 [实施规格](maomi-pet-life-spec.md)。本版需新的实机验收，之前背词版的试玩结论不等于本版已验证。

## 语音操作

先说“猫咪过来”，等屏幕显示正在聆听后，可以说：

| 说什么 | 猫咪做什么 |
| --- | --- |
| 看看你的状态 | 查询饱食、饮水、精力、健康、心情和背包 |
| 喂猫粮 / 铲屎 / 给零食 / 摸摸 | 原有照料，按背包实际消耗 |
| 喝水 | 免费补充饮水 |
| 带你看医生 | 免费恢复健康；健康时不会假装生病 |
| 睡一会儿 / 起床 | 睡八小时 / 清醒两小时，之后恢复正常作息 |
| 领取补给 | 当天补足到两份猫粮、一份猫砂，不发猫爪币 |
| 商店有什么 | 列出商品、价格和照料天数要求 |
| 买一个小球 / 用小球玩 | 分别购买 / 使用玩具；使用不扣币、不发币 |
| 戴上围巾 / 换成小猫窝 | 装备已拥有的物品 |
| 卸下服饰 / 恢复默认房间 | 恢复默认外观，物品保留 |
| 开始背单词 | 唤醒并开始或继续原来的题目 |

日常语音仍需要现有 AI 服务联网；本地保存与生活状态计算不依赖 AI 口头记忆。
同步 [后台人设](maomi-persona.md) 的生活扩展段落；设备也会发布新工具及使用说明。

## 成长和日常生活

日龄从领养出生开始；幼猫/少年猫/成年猫按有效照料日 0/7/21 变化。幼猫体型更小，长大后解锁新用品。
21:00–07:00 猫咪自动睡觉。睡觉只是养成状态，不会关闭设备、唤醒能力、计时或提醒。
生活页显示猫咪、房间、装备和当前需求；屏幕提示不会播报催促音。计时、提醒、充电、对话和背词优先展示。
不同日期经常摸摸会逐渐温顺，经常使用玩具会逐渐活泼；没有亲密度分数，也没有“差猫咪”。

健康低于 60 会提示看医生，健康最低 40；不会死亡或离家。饮水、就医免费，每日基础补给可在没有学习任务时照料。
没来照顾最多补算三天生活消耗，不补发过去的币或物资。调整时间、重复请求不能重复领取当天补给。
基础用品仍可花币购买；耐用品永久拥有，重复购买会拒绝，不会再次扣币。

## 电脑试玩

运行 `python scripts/maomi_simulator.py`，在照料页体验喝水、睡觉、就医、补给；商店里购买并使用玩具和装扮。
快进时间观察成长与生活状态，模拟重启检查结果保留。桌面引擎与设备共用规则；桌面画面不是设备 LCD 的逐像素模拟。

额外的真实 LVGL 界面验证：

```powershell
python scripts/test_maomi_pet_home.py
```

需要本地 managed LVGL、电脑 GCC、CMake、Ninja 和中文字体（可用 `--font` 指定 TTF/TTC）。
在 `.cache/maomi-pet-home-test/` 输出幼猫、成年装扮、睡眠、隐藏和恢复画面。
该测试实际创建 LVGL 控件，并在释放旧字体后重绘，覆盖之前遇到的主题换字库生命周期问题。
电脑字体与固件资源字体不同，实际中文显示、屏幕驱动和语音仍需实机检查。

## 更新和回退

沿用现有学习版分区，已有学习版设备只更新应用，不运行首次迁移，不清空词表或宠物分区。
先备份当前系统区与词表/宠物区；新版读取 v1 存档，保留名字、生日、币、库存、题目和历史。
新增生活状态以健康、饮水、精力充足初始化。首次实际保存写 v2；失败则保留原事务状态。
旧版固件不支持 v2 存档，回退必须结合升级前的存档备份。未知版本或校验失败不会自动重置猫咪。

## 实机验收顺序

2026-09-18 开发验证：143 项主机测试、模拟器启动、真实 LVGL 字体切换及隐藏恢复测试通过；
ESP-IDF 6.0.2 学习版与原版均构建通过。学习版应用 3,054,352 字节，保存在
`.cache/maomi-pet-life-artifacts/`（包含校验记录）；当前 `build/` 是原版验证产物。
已按用户要求跳过备份，仅刷入新版应用；写入校验通过，刷写时系统、词表和宠物存档分区未改变。
设备启动成功，可读取新增生活字段，99 个词条及学习记录仍在（75 个未学、24 个待巩固、0 个已掌握）。
用户已确认将精简人设设置到后台，原文见 `maomi-persona.md`。刷入后用户初步试玩反馈“还不错”；以下交互项目仍需逐项实测，不将初步反馈视为完整验收。

1. 正常启动、加载主题字库；检查原猫咪、币、词表和题目仍在。
2. 背词逐题提交及聆听提示；中途让猫咪睡觉，再开始背词恢复原题。
3. 喝水、就医、补给、购买小球与使用；重启后背包不丢失、不重复扣币。
4. 查看成长、服饰和房间显示；不靠 AI 声称成功代替实际装备状态。
5. 开启倒计时/正计时并暂停、继续、停止；触发提醒与对话，确认生活页让位并恢复。
6. 长时间待机、夜间作息、断网和正常断电恢复。
