# 单词养成游戏

用户确认于 2026-09-17。入口：领养橘猫 → USB 导入自己的词表 → 联网口答 →
猫爪币 → 购买猫粮、猫砂 → 照料成长。每天五词、约 3–5 分钟。

## 已锁定规则

- 领养即出生，旧亲密度和陪伴天数不继承；满 24 小时增加一日龄，年度生日庆祝。
- 删除亲密度及等级；摸摸和陪玩保留，影响心情。不会死亡或离家。
- 初始饱食 100，每天下降 50；猫粮 +25，零食 +5。离线最多补算三天饥饿，年龄不限。
- 每两份猫粮产生一次便便，最多三次；一份猫砂全部清理。
- 每天两次有效喂食和一次有效清理记一个照料日；7/21 日成长里程碑。
- 领养赠六份猫粮、三份猫砂；价格为猫粮 4、猫砂 2、零食 12 币。
- 每日完成五个不同词（短词表取全部）得 10 币；每词首次独立答对 +2，提示后 +1，不叠加；日上限 40。
- 每局动态选最多五词：到期复习优先，然后按 CSV 顺序选新词；不足五词不补题。
- 首次独立答对后隔 1 天复习，再答对隔 3 天复习；连续三次间隔独立答对即掌握，退出日常出题。
- 答错或依赖提示清零连续次数、次日复习，同局纠正不升阶。跳过/听不清不增加掌握次数。
- 已掌握词仅在主人主动要求时复习，答错或依赖提示重新进入待巩固。奖励仍遵守原有每日限制。
- 无到期词和新词时告知等待；全部掌握时提示更换词表或主动复习，不凭空出题。
- 进度查询提供未学、待巩固、已掌握数量；单词页不显示这些统计，只显示当前词与真实聆听状态。
  已掌握按原存档 stage>=3 判断，保留旧版进度。
- CSV UTF-8：word,meaning；最多 1000 词，英文 32 字符，释义 120 字节。
- 一次只学一本；重导保留匹配进度，释义变更重新复习，不能重复领奖。
- 屏幕显示当前英文词，长词缩小并换行；中文出题时不显示英文答案。取消、断网、提醒抢占不丢已确认成绩。
- 2026-09-18 二次试玩修正：单词页底部显示“正在聆听，请回答”“准备聆听，请稍候”或
  “正在朗读，请稍候”；会话结束时提示唤醒继续。聆听提示必须同时满足 Listening 与音频处理已开启。
  每题答案必须提交设备，确认持久化完成后才出下一词；不接受仅口头换题。
- 2026-09-18 试玩修正：默认英文出题时，先显示并朗读英文，再问“这个是什么意思？”，
  等待用户作答，不提前念中文释义。新词、复习和纠正回忆规则一致；仅在作答或求助后解释答案。

## 实现边界

猫咪板级纯 C++ 规则核心；持久化与 USB 在独立工作任务，主任务只负责界面和应用状态。
MCP 命令先返回 pending，随后查询结果；只有持久化成功才返回 completed。
所有消费使用存档 revision 条件写；答案仅绑定 session/question 防止重放，不因开始学习或
照料改变全局 revision 而拒绝当前题。旧答案参数 revision 兼容但不作为作答前提。
词库双槽各 256 KiB，交易 NVS 512 KiB，合计 Flash 尾部 1 MiB。
原应用分区位置不动，学习版资源 7 MiB；独立 release variant，首次 USB 迁移。
词条历史最多 2000，达到上限拒绝继续导入新词；这是防重导刷币的明确存储上限。
不存录音；AI 理解答案，不提供任意加币、发音评分、任意 Flash 写入接口。
