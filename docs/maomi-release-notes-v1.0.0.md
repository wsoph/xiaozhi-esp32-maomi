# 小猫咪 1.0.0 发布说明

- 发布日期：2026-08-29
- Git 标签：`maomi-v1.0.0`
- 板型：`zhengchen/1.54tft-wifi-maomi`
- 芯片：ESP32-S3，16 MB Flash，8 MB PSRAM
- ESP-IDF：6.0.2

## 主要功能

- 240×240 满屏无耳橘猫静态表情和动画，适配带实体橘色耳朵的 1.54 英寸方屏外壳。
- 摸摸、喂食、玩耍互动，以及只增不减的亲密度、等级和陪伴天数。
- 六种联网语言游戏：猫咪猜心、三分钟冒险、故事接龙、猫咪小侦探、记忆旅行箱和快问快答。
- 本地倒计时、指定时间闹钟、喝水/久坐提醒、番茄钟、提醒查询和取消。
- 倒计时使用无耳橘猫脸边框全屏显示 `HH:MM:SS`；到点可中断聆听或说话并优先提醒。
- 自定义唤醒词、本地唤醒回应、安静模式、自主动画、充电与低电量表现。
- 电量降至 20% 时播放一次语音充电提示，电量恢复后才允许下一次触发。
- 后台人设 0.5，包含完整功能介绍、六种游戏选择流程和工具真实性规则。

## 行为调整

- 互动过程不再播放独立猫叫，避免音频等待影响后续语音响应。
- 删除“不许说是/不是”游戏。
- 无倒计时时显示橘猫表情；有倒计时时隐藏 AI 字幕、网络和电量图标，优先显示倒计时。

- 完整主机测试：115/115 通过。

## 恢复

稳定版发布包保存 bootloader、分区表、OTA 初始数据、资源分区和应用分区，并附带刷写参数、调试 ELF/MAP、后台人设及 SHA-256 清单。恢复时应按 `flasher_args.json` 写入全部五个分区，不只恢复应用分区。
