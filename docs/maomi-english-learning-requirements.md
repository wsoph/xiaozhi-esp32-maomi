# 小猫咪英语学习功能需求初稿

## 文档状态

- 状态：需求澄清中
- 日期：2026-08-30
- 说明：本文只记录当前已经提出的需求和约束，不代表实现方案已经确定。

## 背景

小猫咪 1.0 是一款 AI 猫咪桌面宠物，现有宠物互动构成产品的核心功能。新功能应在保留这些核心体验的基础上，为儿童、成人等所有英语学习者增加英语学习与陪练能力。

## 核心目标

- 让小猫咪陪儿童和成人等英语学习者练习英语口语，帮助不同年龄、不同水平的用户提高英语口语能力。
- 学习过程继续体现“小猫咪陪伴用户”的产品定位，而不是把设备变成以屏幕阅读为主的学习机。
- 功能不能绑定单一年龄段；具体内容、难度、语速和反馈方式应能适配用户水平与学习目标。

## 当前期望的学习内容

1. 英语口语练习是主要功能。
2. 可以加入英语单词记忆或背诵练习。
3. 在符合屏幕与护眼约束的前提下，可以进一步考虑英语听、说、读、写、词汇和语法方面的练习。
4. 上述扩展内容目前只是允许探索的范围，具体练习形式、优先级和首期范围尚未确定。

## 屏幕与护眼硬约束

- 设备使用 1.54 英寸屏幕，不应要求孩子在屏幕上阅读很小的文字。
- 屏幕不能呈现需要持续阅读的长英语句子或长篇学习内容。
- 单次画面只接受显示一个英语单词，或者简短的中文解释。
- 英语句子、长对话和较长教学内容应优先通过语音完成，不能依赖小屏幕阅读。
- 任何听、说、读、写、词汇或语法练习都必须先满足以上显示限制。

## 与小猫咪 1.0 的关系

- 英语学习是新增能力，不能重新实现、替换或无意破坏现有宠物核心功能。
- 新功能应保留 AI 猫咪桌面宠物的陪伴感。
- 学习功能与摸摸、喂食、陪玩、语言游戏、提醒、聆听和说话等既有能力之间的优先级及冲突规则仍需确认。

## 待确认事项

- 如何识别用户的年龄层、当前英语水平和学习目标，并据此调整练习。
- 最重要的口语场景，以及希望优先改善的能力，例如敢开口、发音、日常对话或课内巩固。
- 学习功能的触发方式、单次练习时长和结束方式。
- 小猫咪如何示范、倾听、纠错、鼓励，以及错误多次发生时如何处理。
- 是否需要课程、等级、学习进度、复习计划、奖励或家长反馈。
- 单词范围、选词来源、复习机制，以及是否需要拼写练习。
- “简短的中文解释”允许的最大信息量和具体显示形式。
- 听、读、写和语法练习中哪些内容进入首期范围。
- 是否依赖联网 AI、设备端 MCP 工具或新的本地持久化数据。
- 学习过程与现有功能发生冲突时的优先级、中断和恢复规则。
- 成功、失败、取消、断网等流程，以及最终真机验收标准。

## 当前范围边界

- 未经进一步确认，不假设儿童水平、课程体系、练习流程或评分方式。
- 未经明确授权，不刷机、提交、推送或合并。
